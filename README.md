# 🌐 ZEESHU Web Portal

### A Modern & Responsive Personal Web Portal

**ZEESHU Web Portal** is a modern personal website built using HTML, CSS, and JavaScript. It showcases professional information, technical skills, services, featured projects, and an interactive login and contact interface.

## 🚀 About The Project

ZEESHU Web Portal is designed to create a professional online presence with a modern dark-themed user interface and cyan highlights.

The website combines responsive web design, interactive JavaScript functionality, professional portfolio sections, and EmailJS contact form integration.

## 💻 How To Run Locally

Follow these simple steps to run the project on your computer.

**1. Clone the Repository**

```bash
git clone https://github.com/zeeshanahmad03/ZEESHU-Web-Portal.git
```

**2. Open Project Folder**

```bash
cd ZEESHU-Web-Portal
```

**3. Run the Website**

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

No additional installation is required for the current frontend version.

## 📧 EmailJS Configuration

The contact form uses EmailJS to send messages.

To configure it:

1. Create an EmailJS account.
2. Set up an email service.
3. Create an email template.
4. Configure your EmailJS public key in `index.html`.
5. Verify your Service ID and Template ID in `script.js`.
6. Test the contact form.

## 🔐 Authentication Information

The current login and signup functionality is a frontend demonstration using JavaScript and browser storage.

Backend authentication, MongoDB integration, secure password hashing, and actual password reset emails are not yet implemented.

These features can be added in future versions using Node.js, Express.js, and MongoDB.

## 🌍 Deployment

This project can be hosted for free using GitHub Pages.

**Deployment Steps:**

1. Open your GitHub repository.
2. Go to Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch.
6. Select `/ (root)`.
7. Click Save.
