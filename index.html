About Me

AI/ML and Python developer in the making. I’m a B.Tech CSE (AI/ML) student at MACET, Patna (graduating 2027), with hands-on experience in web development and a strong interest in NLP and deep learning.

I’m currently building ZEESHU, a web portal that offers a Web Design & Development Course. I’m working on it end to end, from designing the database to building the backend and frontend using HTML, CSS, JavaScript, Node.js, MongoDB. Along the way I’ve learned how to structure a real application, handle user data, and debug problems the way they happen in real projects. Next, I plan to integrate an AI-powered conversational chatbot and smart recommendation system to personalize the learning experience.

My experience so far:

  • Web Developer Intern at Internbee (Jun 2025 to present), where I built responsive web components, optimized database queries, and implemented RESTful APIs for production features
  • Intern at Soft Intern, where I developed interactive frontend modules, debugged state management issues, and ensured cross-browser compatibility
  • Participant in a 2-day hackathon at BIT (14-15 Jan 2026), where I learned to build fast and collaborate under pressure
